# Coding Agent Workflow / 编码代理工作流

## 中文

1. 阅读根目录 `AGENTS.md` 和所有受影响文档。
2. 确认任务处于已批准范围；对破坏性、发布、部署、迁移或付费变更先取得所有者批准。
3. 以最小可审查差异实现；同步修改文档、合同、图表和测试。
4. 不使用真实患者数据或凭据；不添加未经论证的基础设施或依赖。
5. 执行最小相关验证；记录确切命令和结果，明确未运行的检查。
6. 检查差异、秘密和文档双语一致性；不提交无关文件。
7. 总结最终行为、变更文件、验证与未决项，不编造成功结果。

当前阶段只做文档、架构和合同准备；未经批准不写业务实现。

## English

1. Read root `AGENTS.md` and all affected documentation.
2. Confirm the task is approved; obtain owner approval before destructive, release, deployment, migration, or paid-service changes.
3. Make the smallest reviewable change; update docs, contracts, diagrams, and tests together.
4. Use no real patient data or credentials; add no unjustified infrastructure or dependency.
5. Run the smallest relevant validation; record exact commands and results, including checks not run.
6. Review the diff, secrets, and bilingual consistency; exclude unrelated files.
7. Report final behavior, changed files, validation, and open issues truthfully.

This phase is limited to documentation, architecture, and contract preparation; business implementation requires approval.
