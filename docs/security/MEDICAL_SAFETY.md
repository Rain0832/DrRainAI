# 医疗安全



**用途边界：**信息辅助，不是确诊、分诊、处方、治疗指令或专业医护替代。不得声称具备临床有效性或法规合规性。

### 交互要求（待产品/临床评审）

- 固定提示文案为：“本助手仅提供健康信息参考，不构成诊断或治疗建议。模型可能出错；如症状严重、突然恶化或存在危险，请立即联系当地急救服务或合格医疗人员。”
- 对信息不足或不确定内容直接说明不确定，不虚构证据、来源、检查结果或个人病史。
- 不虚构证据、来源、检查结果或个人病史；没有可靠依据时不作确定结论。
- 对可能危及生命或紧急症状，提示立即联系当地急救服务或合格医疗专业人员；不得延误求助。
- 不提供可能促成伤害的确定性诊断、药量调整或替代医生建议。
- 工具只能执行已批准的低风险能力；任何高影响操作需人工确认，默认不开放。
- 高风险识别能力及文案须经临床与法律相关方评审，并使用合成测试验证；目前尚未实现或验证。

医疗场景、目标地区、用户年龄和高风险升级标准仍待所有者确认；上述提示文案作为 MVP 默认文案，正式发布前需进行产品与临床评审。
