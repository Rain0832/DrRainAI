# Configuration / 配置

## 中文

当前没有服务配置或真实密钥。实现阶段应为每个配置项记录所有者、用途、类型、默认策略、是否敏感及校验规则。

- 通过受控环境或密钥管理服务注入秘密；不得置于源码、样例、日志或客户端 bundle。
- 对地址、端口、超时、请求大小、速率、Agent 迭代/模型/工具预算设置类型化校验；缺少必要配置时显式启动失败。
- 不在本文件中定义未经实现验证的环境变量名称或默认阈值。
- `.env.example` 仅允许无效占位值，并不得由真实 `.env` 复制生成。
- 生产、测试和开发凭据必须隔离；轮换和撤销流程待设计。

## English

No service configuration or real secrets exist yet. During implementation, document each setting's owner, purpose, type, default policy, sensitivity, and validation.

- Inject secrets through a controlled environment or secret manager; never place them in source, examples, logs, or client bundles.
- Type-check addresses, ports, timeouts, request sizes, rates, and Agent iteration/model/tool budgets; fail startup explicitly when required configuration is missing.
- Do not define unverified environment-variable names or thresholds here.
- `.env.example` may contain invalid placeholders only and must not be generated by copying a real `.env`.
- Isolate production, test, and development credentials; rotation/revocation processes remain to be designed.
