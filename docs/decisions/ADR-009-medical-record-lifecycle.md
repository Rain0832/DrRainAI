# ADR-009：医疗数据生命周期

- 状态：提案；需所有者批准

## 背景

医疗记录需要在导入、校验、人工复核和发布之间保持清晰边界，避免未确认内容进入 AI 检索。

## 决定

医疗数据按以下顺序流转：

```text
Import -> Validate -> Review -> Publish
```

只有状态为 `Published` 的数据版本才可通过检索或 Evidence API 提供给 AI。导入、校验失败、待复核和被拒绝的数据不得用于 AI 检索；每次发布必须保留版本、来源和审计信息。

## 影响

Core 负责状态转换、租户隔离、资源级授权和版本一致性；Agent Runtime 只接收已授权的已发布证据。人工复核增加流程成本，但降低未经确认数据被推理使用的风险。

## 复审条件

当医疗记录类型、复核责任、撤回/更正语义或法规要求明确后复审。
