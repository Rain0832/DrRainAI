# ADR-0007：API 合同

- 状态：提案；需所有者批准

## 背景

跨语言服务需要稳定、可验证的请求、错误和流事件格式。

## 备选方案

HTTP/JSON 与 OpenAPI/JSON Schema；gRPC/Protobuf；混合方案。

## 决定

提议 HTTP/JSON + OpenAPI + JSON Schema + SSE；接口当前为草案，不定义未确认的最终路径。

## 影响

人类可读且语言无关；需制定兼容、版本、验证和生成流程。

## 风险

规范与实现漂移；事件命名或终态语义不一致。

## 复审条件

在真实服务性能、代码生成或协议能力要求经测量不满足时复审。
