# ADR-0006：Agent 运行时

- 状态：提案；需所有者批准

## 背景

需要模型适配和受限工具执行，同时让 Core 保持业务与持久化权威。

## 备选方案

Agent 直接置于 Core；独立 Python Runtime；多 Agent 编排平台。

## 决定

提议 Python 单 Agent Runtime，默认无工具；工具须逐项批准、类型校验、授权、超时和审计。Agent 不直连数据库。

## 影响

运行时可独立限制和取消；跨语言与供应商 SDK 带来维护成本。

## 风险

模型调用成本难精确衡量；工具提示注入或副作用造成风险。

## 复审条件

团队能力、模型供应商、工具需求和运行隔离要求明确后复审；未经证据不采用多 Agent。
