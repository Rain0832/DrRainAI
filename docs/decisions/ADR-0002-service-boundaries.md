# ADR-0002：服务边界

- 状态：提案；需所有者批准

## 背景

需要隔离公开入口、权威业务规则与模型/工具执行。

## 备选方案

单体、分层模块化单体、独立 Web/Gateway/Core/Agent 进程。

## 决定

逻辑上采用 Web、Go Gateway、C++ Core、Python Agent Runtime 四个边界；部署初期可按团队与运维能力合并进程，须经 ADR 评审。

## 影响

职责清晰但增加跨进程合同、构建和运维成本。

## 风险

为技术分层过度拆分；跨服务错误及取消传播处理不全。

## 复审条件

团队规模、可靠性需求、部署成本或测量到的扩展瓶颈表明边界不合适时复审。
