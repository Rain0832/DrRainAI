# ADR-0004：主数据库

- 状态：暂定建议；需所有者批准

## 背景

候选域数据包括用户/主体、会话、消息、运行及审计事件，要求一致性和所有权校验。旧项目数据模型与迁移成本尚未审计。

## 备选方案

PostgreSQL 与 MySQL。两者均具事务、成熟驱动和迁移工具；旧项目兼容性、团队熟悉度和现有托管条件未知。

## 决定

绿地候选优先 PostgreSQL，因其关系事务与扩展生态适合候选数据；并非已批准决定。首期使用普通关系/文本能力，不预设 pgvector。

## 影响

可用单一关系库实现初期持久化；需评估运维、备份、驱动和迁移策略。更换数据库会产生模式与数据迁移成本。

## 风险

团队或旧数据更适合 MySQL；过早依赖 PostgreSQL 专有功能会增加锁定。

## 复审条件

旧系统审计、团队能力、托管要求、事务/查询基准及检索需求明确后，由所有者批准。仅在检索指标证明必要时评估 pgvector。
