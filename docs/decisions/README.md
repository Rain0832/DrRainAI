# Architecture Decision Records / 架构决策记录

## 中文

ADR 记录重要选择、备选方案、代价、风险与复审条件。标为“提案”或“待批准”的决定不构成实施授权；更新决定时保留历史并添加新 ADR。

| ADR | 主题 | 状态 |
|---|---|---|
| [0001](ADR-0001-repository-and-migration.md) | 独立仓库与旧项目迁移 | 提案 |
| [0002](ADR-0002-service-boundaries.md) | 服务边界 | 提案 |
| [0003](ADR-0003-frontend.md) | 前端 | 提案 |
| [0004](ADR-0004-primary-database.md) | 主数据库 | 暂定，待批准 |
| [0005](ADR-0005-local-development-and-deployment.md) | 本地开发与部署 | 提案 |
| [0006](ADR-0006-agent-runtime.md) | Agent Runtime | 提案 |
| [0007](ADR-0007-api-contracts.md) | API 合同 | 提案 |

## English

ADRs record significant choices, alternatives, consequences, risks, and revisit criteria. A proposed or pending-approval decision does not authorize implementation. Preserve history and add a new ADR when superseding a decision.
