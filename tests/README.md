# Test Layout / 测试目录约定

## 中文

当前没有业务实现或测试夹具。获批实施后，按测试范围创建 `contract/`、`integration/`、`e2e/` 和 `evaluation/`；仅当目录含有实际测试文件时纳入版本控制，不创建空占位文件。所有样例必须为合成数据。

## English

There is no business implementation or test fixture yet. After implementation approval, create `contract/`, `integration/`, `e2e/`, and `evaluation/` according to test scope. Track a directory only when it contains real tests; do not add empty placeholders. All examples must use synthetic data.
