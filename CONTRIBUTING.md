# Contributing / 贡献指南

## 中文

本阶段接受产品、架构、合同和治理文档的精确改进；不接受未经批准的业务实现或生产变更。

- 先阅读 [AGENTS.md](AGENTS.md) 和相关主题文档。
- 文档与代码注释均须中英双语；每种语言应表达相同的最终结论。
- 接口变更须同步更新 `contracts/`、组件边界和相关图表。
- 使用合成示例；禁止患者信息、真实凭据、日志和生产配置。
- 提交前检查差异与格式；不得声称未运行的检查通过。
- 小步提交，说明最终行为和验证结果，不写中间过程。
- 许可证尚未选择；贡献者不得假定仓库采用特定开源许可证。

## English

During this phase, contributions should improve product, architecture, contracts, and governance documentation. Unapproved business implementation or production changes are out of scope.

- Read [AGENTS.md](AGENTS.md) and relevant topic documents first.
- Documentation and code comments must be bilingual; both languages must express the same final conclusions.
- Interface changes must update `contracts/`, component boundaries, and affected diagrams.
- Use synthetic examples only; never add patient information, real credentials, logs, or production configuration.
- Review the diff and formatting before submission; do not claim checks that were not run.
- Keep commits small and report final behavior and validation, not intermediate steps.
- The license is undecided; contributors must not assume a particular open-source license.
