# Security Policy / 安全策略

## 中文

### 当前状态

本仓库尚处于文档与架构评审阶段，未提供可运行服务。安全设计见 [威胁模型](docs/security/THREAT_MODEL.md)、[医疗安全](docs/security/MEDICAL_SAFETY.md) 和 [隐私与保留](docs/security/PRIVACY_AND_RETENTION.md)。不作合规或安全认证声明。

### 报告问题

不要在公开 Issue 中发布凭据、患者信息、可利用细节或真实日志。通过仓库所有者提供的私密渠道报告；当前未配置专用安全邮箱或披露平台。涉及真实健康信息时，应避免复制或转发该信息。

## English

### Current status

This repository is in documentation and architecture review and provides no runnable services. See the [Threat Model](docs/security/THREAT_MODEL.md), [Medical Safety](docs/security/MEDICAL_SAFETY.md), and [Privacy and Retention](docs/security/PRIVACY_AND_RETENTION.md). No compliance or security certification is claimed.

### Reporting

Do not publish credentials, patient information, exploit details, or real logs in a public issue. Report concerns through a private channel provided by the repository owner; no dedicated security email or disclosure platform is configured. Avoid copying or forwarding real health information.
