# DrRainAI

## 中文

DrRainAI 是面向智能医疗助手的**文档与架构初始化仓库**。当前仓库定义产品范围、组件边界、安全原则和待评审接口；尚未包含可运行的业务服务，也不代表已有任何医疗能力。

助手的目标是提供信息支持，不提供确诊或替代专业临床判断。产品需求、医疗安全边界、身份模式、数据保留和许可证均须经所有者评审。

从 [产品规格](docs/product/PRODUCT_SPEC.md) 和 [MVP 范围](docs/product/MVP_SCOPE.md) 开始。仓库规则见 [AGENTS.md](AGENTS.md)，架构决策记录见 [决策目录](docs/decisions/README.md)。

## English

DrRainAI is a **documentation and architecture bootstrap** for an intelligent healthcare assistant. This repository defines product scope, component boundaries, security principles, and draft interfaces. It contains no runnable business services and does not claim that any medical capability exists.

The assistant is intended for informational support, not diagnosis or replacement of professional clinical judgment. Product requirements, medical safety boundaries, identity mode, data retention, and licensing require owner review.

Start with the [Product Specification](docs/product/PRODUCT_SPEC.md) and [MVP Scope](docs/product/MVP_SCOPE.md). Repository rules are in [AGENTS.md](AGENTS.md); architecture decisions are indexed in [the decisions directory](docs/decisions/README.md).
